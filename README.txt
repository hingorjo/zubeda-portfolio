HOW TO PREVIEW
--------------
Open index.html in a browser, or use the VS Code Live Server extension.

ADD THE REAL PDF DOCUMENTS
--------------------------
Copy the original PDF files into assets/documents/ and rename them exactly:

- internship-log.pdf
- internship-reflective-log.pdf
- internship-report.pdf
- internship-objectives.pdf
- supervisor-log.pdf
- internship-completion-letter.pdf

The View button opens a built-in PDF preview. Download saves the original PDF.
If your PDF filenames differ, update the data-file and href values in index.html.

ADD REAL PHOTOGRAPHS
--------------------
Copy the original internship evidence photographs into assets/images/ and name them:

- evidence-01.jpg
- evidence-02.jpg
- evidence-03.jpg
...
- evidence-11.jpg

The gallery automatically displays available numbered images. JPG is recommended.
You can add more by adding filenames to the evidenceFiles array in js/main.js.

CONTENT TO VERIFY
-----------------
The original Google Sites page displays the internship date as:
"14sept-24oct 26". This starter page formats it as
"14 September – 24 October 2026". Please verify the year before publishing.

The original page's evidence images and embedded documents were not copied into
this starter package. Add the actual files before publishing.
